# 市场杠杆风险监测

> **核心指标**：融资余额 / 流通市值 > 4% 触发风险警示。

## 数据架构

```
AKShare (唯一数据源)
  ├── stock_margin_detail_szse(date) → 深市融资融券明细
  ├── stock_margin_detail_sse(date)  → 沪市融资融券明细
  └── 流通市值: 用户传入 / 内置参考数据
```

## 执行步骤

```bash
SKILL_DIR=~/.claude/skills/leverage-risk

# 运行杠杆风险分析 (使用内置参考流通市值)
python3 $SKILL_DIR/scripts/leverage_risk.py

# 传入最新流通市值（推荐，来自交易所官方统计）
python3 $SKILL_DIR/scripts/leverage_risk.py \
  --cyb-mv 144934.15 \
  --kcb-mv 107381.71 \
  --sz-main-mv <深市主板流通市值> \
  --sh-main-mv <沪市主板流通市值> \
  --total-mv <沪深总流通市值>

# 指定融资余额日期
python3 $SKILL_DIR/scripts/leverage_risk.py --date 20260717

# JSON 输出
python3 $SKILL_DIR/scripts/leverage_risk.py --json

# 自定义风险阈值
python3 $SKILL_DIR/scripts/leverage_risk.py --threshold 5.0
```

## 数据获取方式

### AKShare 接口（全板块）

| 数据 | 接口 | 说明 |
|------|------|------|
| 深市融资融券明细 | `stock_margin_detail_szse(date)` | 含创业板(300/301)、深主板(000/002) |
| 沪市融资融券明细 | `stock_margin_detail_sse(date)` | 含科创板(688)、沪主板(60) |

**板块分类规则**：
| 板块 | 代码前缀 | 交易所 |
|------|---------|--------|
| 创业板 | 300、301 | 深市 |
| 科创板 | 688 | 沪市 |
| 深市主板 | 000、002、003 | 深市 |
| 沪市主板 | 60 | 沪市 |

### 流通市值

各板块总流通市值**无公开实时接口**，支持两种方式：

**方式A：用户传入（推荐）**
从交易所官方统计/万得等数据源获取流通市值，通过命令行参数传入：
```bash
--cyb-mv 144934.15   # 创业板流通市值(亿元)
--kcb-mv 107381.71   # 科创板流通市值(亿元)
--sz-main-mv <值>     # 深市主板
--sh-main-mv <值>     # 沪市主板
--total-mv <值>       # 沪深两市合计
```

**方式B：内置参考值**
脚本内置了验证过的参考数据（2026-07-17），未传参时使用。

> **重要**：流通市值应定期更新（建议每月或每季度），以保证比例计算准确。

## 风险阈值

| 融资余额/流通市值 | 状态 | 标识 |
|-------------------|------|------|
| ≤ 4% | 安全 | 🟢 |
| > 4% | 风险警示 | 🔴 |

```
akshare >= 1.0
```

## 数据时效性

- 融资融券数据：交易日 T+1 更新（次日公布前一交易日数据）
- 流通市值：需定期手动更新（通过参数或修改脚本内置参考值）
